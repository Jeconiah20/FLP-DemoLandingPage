### FLP-DemoLandingPage
- A single-page landing page with multiple sections
- A lead generation tool – captures phone numbers from potential customers
- A loan calculator – helps users estimate EMI before applying
- A brand showcase – displays services, trust factors, and NBFC partners

### ✨ Features

- **Hero Section** - Dynamic typing effect with loan calculator
- **EMI Calculator** - Interactive sliders for loan amount and tenure
- **Services** - Fast approval, flexible EMIs, secure processing
- **Why Choose Us** - Trusted experts, 256-bit encryption, user-friendly platform
- **NBFC Partners** - Trusted financial partners display
- **Responsive Design** - Works seamlessly on mobile, tablet, and desktop
- **Smooth Animations** - Scroll-triggered fade-in effects and micro-interactions
- **Stats Bar** - Social proof with animated counters

 ### 🛠️ Tech Stack

- **React 18** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Icon library
- **Intersection Observer API** - Scroll animations

### 🚀 Getting Started

#### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

#### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/flp-loans.git
cd flp-loans

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

### 🌐 Deployment

The project is deployed on Netlify:

**Live URL:** [https://flp-demo-landing-page.netlify.app/](https://flp-demo-landing-page.netlify.app/)

To deploy via drag & drop:
1. Run `npm run build`
2. Drag the `dist` folder to [app.netlify.com/drop](https://app.netlify.com/drop)
